### Hi, I'm Zafer 👋

Senior .NET engineer at **[Raklet](https://raklet.com)**, a multi-tenant SaaS platform that clubs,
associations, universities and nonprofits use to run memberships, events, payments and communities.
I joined in 2018 to build the test automation from scratch, moved into full-stack engineering,
and today lead hands-on delivery across the core platform.

**What I work on**
- 💳 **Payments & billing**: Stripe & Stripe Connect, SEPA/ACH direct debit, PayPal, Iyzico; recurring billing, scheduled payments, coupons, refunds, saved cards, provider webhooks
- 🧩 **Multi-tenant membership SaaS**: plans and multi-currency pricing, applications, checkout, member portal, CRM/admin workflows, localization
- ⚙️ **Background processing**: continuous and scheduled Azure WebJobs, Service Bus and storage queues, Node.js Azure Functions
- 🔐 **Auth & APIs**: ASP.NET Identity, OAuth 2.0 bearer tokens, JWT, external login providers, REST APIs documented with Swagger/OpenAPI
- 🛡️ **Reliability**: idempotency, webhook replay safety, null-safety guards, async/await deadlock prevention, parameterized SQL, telemetry-driven debugging
- 🧪 **Testing & delivery**: a C# Selenium WebDriver framework built from scratch, MSTest/VSTest and Jest suites, Azure DevOps and GitHub Actions pipelines with automated browser tests gating releases
- 🤖 **AI-assisted engineering**: repository agent instructions, reusable skills and MCP integrations; agent workflows (Claude Code, Codex) that take work from triage to a reviewed PR, with CI gates and human review kept in the loop

**By the numbers:** 3,900+ pull requests authored · 3,400+ merged into Raklet's core platform
